# assets/logo/

Place additional brand logo files here (SVG preferred). The current logomark
used in the header, footer, favicon, and social preview is defined inline in
each HTML file and in `favicon.svg` / `social-preview.svg` at the repository
root, so this folder is currently empty.

Only individually-reviewed, public-safe branding artwork belongs here —
never Android source, screenshots with real client data, or files copied
wholesale from the private `~/cosmofy` app repository.
