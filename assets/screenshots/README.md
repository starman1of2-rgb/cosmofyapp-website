# assets/screenshots/

Real Cosmofy app screenshots, used on the homepage hero and the "See it in
action" gallery. Each was individually reviewed before being added here to
confirm it contains no client names, contact information, formulas,
photographs, financial data, or other private salon records — every visible
name/number is test data ("Play Test" as the client, `555-01XX`-style
fictional phone numbers), not a real client.

| File | Used for |
|---|---|
| `01-hero-home-next-appointment.webp` | Homepage hero |
| `02-calendar-month-appointment-counts.webp` | Gallery — Month view appointment counts |
| `03-calendar-week-outside-hours.webp` | Gallery — outside-business-hours labeling |
| `05-clients-list.webp` | Gallery — client list |
| `07-new-appointment.webp` | Gallery — date/time pickers |
| `08-checkout.webp` | Gallery — checkout |
| `09-money-dashboard.webp` | Gallery — money dashboard / daily close |
| `10-backup-and-restore.webp` | Gallery — encrypted backup/restore |

To replace or add a screenshot: review it against the checklist above, drop
it in this folder, and reference it from `index.html`'s hero or
`.screenshot-gallery` markup with descriptive `alt` text that never
mentions a name or number visible in the image itself.
